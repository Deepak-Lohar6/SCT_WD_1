# ❖ NovaSync — Intelligent Team Execution

A modern, high-performance responsive landing page built for an autonomous workflow and team execution platform. Developed using HTML5, CSS3, and modern JavaScript.

---

## 🚀 Overview

**NovaSync** is designed to showcase an enterprise-grade AI workflow engine. The landing page features a sleek dark-mode aesthetic, interactive components, responsive design across all viewports, and custom modal handling—built entirely with native web technologies.

This project fulfills **Task 01: Responsive Landing Page** for the **SkillCraft Technology Web Development Internship**.

---

## ✨ Features

* **Interactive Navigation:** Pinned top navbar with glassmorphism effects and dynamic background transitions on scroll.
* **Responsive Layout:** Adaptive design using CSS Flexbox and Grid, fully optimized for mobile, tablet, and desktop screens.
* **Mobile Drawer:** Custom slide-down navigation menu built for smaller viewports.
* **Interactive UI Elements:** 
  * Animated telemetry statistics & status pills.
  * Plan options with feature highlights.
  * Functional modal system responding to user actions and button triggers.
  * Integrated contact form with automated event handlers.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, CSS variables, Flexbox, Grid, keyframe animations, and media queries.
* **JavaScript (ES6+):** Event listeners, DOM manipulation, scroll handlers, and modal logic.
